# henox — Kişisel Portfolyo Scripti

Kendi kişisel sitem için hazırladığım siyah & mor temalı, Discord Lanyard API destekli ve çift dilli (TR/EN) portfolyo projesi. Geliştirmeye açık bir scripttir, dilediğiniz gibi düzenleyip kullanabilirsiniz.

- **Geliştirici:** henox ([@Henox77](https://github.com/Henox77))
- **Discord:** `1462496241693753558`

---

## 🛠️ Kullanılan Teknolojiler

- **Framework:** Next.js (App Router), React 19, TypeScript
- **Stil:** Tailwind CSS (Siyah & Mor Koyu Tema)
- **API Entegrasyonu:** Discord Lanyard API (REST & WebSocket)
- **İkonlar:** Simple Icons, Lucide React
- **Paket Yöneticisi:** pnpm

---

## ⚡ Özellikler

- Siyah ve mor renk paleti (Pure Black & Neon Purple)
- Canlı Discord durumu, Spotify dinleme bilgisi ve aktif kodlama bilgisi (Lanyard API)
- Tek tıkla Türkçe / İngilizce (TR/EN) dil değiştirme
- Canlı GitHub katkı grafiği (@Henox77)
- Mobil uyumlu ve hızlı arayüz

---

## 🚀 Kurulum

Projeyi çalıştırmak için:

```bash
# Paketleri yükleyin
pnpm install

# Geliştirme sunucusunu başlatın
pnpm dev
```

Derlemek ve canlıya almak için:

```bash
pnpm run build
pnpm start
```
